# 행사 아카이브

회사 행사의 **사진 · 언론기사 · 영상**을 한 화면에서 확인하고 내려받는 자료 보관소입니다.
지원사업 신청서에 붙일 증빙(행사 사진, 언론보도 등)을 흩어진 폴더에서 찾지 않고 한 번에 챙기는 것이 목적입니다.

---

## 쓰는 법

**`index.html` 을 더블클릭**하면 바로 행사 목록이 열립니다. 별도 설치나 서버가 필요 없고,
폴더째 회사 공유드라이브에 올려두면 다른 직원도 그대로 열어볼 수 있습니다.

다만 이렇게 열면 브라우저 정책 때문에 **사진과 PDF 를 클릭했을 때 저장되지 않고 새 탭에서 열립니다**
(ZIP 은 그대로 저장됩니다). 사진·PDF 까지 클릭 한 번으로 저장하려면 **`열기.cmd` 를 더블클릭**하세요.
같은 화면이 `http://localhost:8787/` 로 열리고 모든 내려받기가 바로 저장됩니다. (Node.js 필요)

| 하고 싶은 것 | 방법 |
|---|---|
| 행사 찾기 | 위쪽 검색창에 행사명·주관사·언론사·장소를 입력 (`/` 키로 검색창 이동) |
| 증빙 있는 행사만 보기 | `언론기사 있는 행사만` 버튼 |
| 행사 자료 한 번에 받기 | 목록 오른쪽 내려받기 버튼, 또는 미리보기의 `전체 내려받기` |
| 기사 원문 보관본 받기 | 미리보기 → 관련 자료 → `PDF 저장` |
| 사진 크게 보기 | 미리보기 사진 클릭 (`←` `→` 로 넘기고 `Esc` 로 닫기) |
| 사진 한 장만 받기 | 크게 보기 화면의 `이 사진 저장` |
| 특정 행사 링크 공유 | 주소창의 `#e04` 형태 주소를 그대로 전달 |

### 전체 내려받기에 들어있는 것

행사별 ZIP 한 개에 아래가 모두 들어갑니다. 그대로 제출 폴더에 넣으면 됩니다.

```
20251209_2025 일터혁신 컨퍼런스 — 일터혁신 우수기업 선정.zip
├─ 사진(원본)/      촬영 원본 해상도 그대로
├─ 언론기사/        기사 원문 PDF + 지면 캡처 이미지
├─ 영상/            행사 영상 파일 (있는 경우)
└─ 행사정보.txt     일시·장소·주관·참석자·기사 링크·사진 목록
```

## 새 행사 추가하기

### 1. 사진 넣기

`source/` 아래에 `구분/행사명_날짜` 형식으로 폴더를 만들고 사진을 넣습니다.

```
source/
├─ 사내 행사/
│   └─ 산업안전보건 교육_260121/     ← 사진 그대로 복사
└─ 사외 행사/
    └─ 포스코 기술나눔 행사_260318/
```

### 2. 행사 정보 적기

`data/events.json` 의 `events` 배열에 항목을 추가합니다. 기존 항목을 복사해 고치는 것이 가장 쉽습니다.

```jsonc
{
  "id": "e13",                                  // 겹치지 않는 번호. 한 번 정하면 바꾸지 마세요
  "folder": "사외 행사/새 행사_260901",           // 위에서 만든 source 폴더 경로
  "category": "사외",                            // 사내 | 사외
  "type": "수상",                                // 목록의 행사구분
  "date": "2026-09-01",
  "title": "행사 이름",
  "subtitle": "한 줄 부제",
  "place": "장소",
  "host": "주관 기관",
  "attendees": "참석자",
  "summary": "행사 개요 한두 문장",
  "notes": ["단체사진 좌측 세번째 ○○○ 상무"],     // 사진 속 인물 위치 등 메모
  "articles": [
    { "press": "언론사", "title": "기사 제목", "url": "https://...", "hasPhoto": true }
  ],
  "videos": [
    { "press": "채널명", "url": "https://...", "marks": ["12:30~ 대표이사 인터뷰"] }
  ]
}
```

### 3. 다시 빌드

```bash
cd tools
npm install        # 처음 한 번만
npm run articles   # 기사 원문을 PDF 로 저장 (이미 받은 기사는 건너뜀)
npm run build      # 사진 변환 · ZIP 묶기 · 목록 갱신
```

`npm run build` 를 마치면 `index.html` 을 새로 고침하는 것만으로 반영됩니다.

## 폴더 구조

| 폴더 | 내용 | 직접 수정 |
|---|---|---|
| `index.html`, `assets/app.css`, `assets/app.js` | 화면 | 예 |
| `열기.cmd` | 로컬 서버로 여는 실행 파일 (선택) | 예 |
| `data/events.json` | **행사 정보 원본. 여기만 고치면 됩니다** | 예 |
| `source/` | 사진 원본 (입력) | 예 |
| `photos/`, `thumbs/` | 화면용으로 줄인 사진 (긴 변 1920px) | 아니오 — 빌드가 생성 |
| `articles/` | 기사 PDF·캡처 | 아니오 — 빌드가 생성 |
| `videos/` | 행사 영상 파일 | 아니오 — 빌드가 생성 |
| `downloads/` | 행사별 전체 ZIP | 아니오 — 빌드가 생성 |
| `assets/data.js` | 화면이 읽는 목록 데이터 | 아니오 — 빌드가 생성 |
| `tools/` | 빌드 스크립트 | 예 |

`source/` 와 생성 폴더는 용량이 커서 `.gitignore` 에 넣어 두었습니다.
저장소에는 화면·스크립트·`data/events.json` 만 올라가고, 사진과 ZIP 은 공유드라이브로 관리합니다.
(저장소에 사진까지 올리려면 Git LFS 를 붙여야 하고 GitHub 무료 용량을 넘깁니다.)
