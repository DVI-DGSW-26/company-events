# 행사 아카이브

회사 행사의 **사진 · 언론기사 · 영상**을 한 화면에서 확인하고 내려받는 자료 보관소입니다.
지원사업 신청서에 붙일 증빙(행사 사진, 언론보도 등)을 흩어진 폴더에서 찾지 않고 한 번에 챙기는 것이 목적입니다.

---

## 사이트 띄우기

**`열기.cmd` 를 더블클릭**하면 사이트가 뜹니다. 터미널에서는 `npm run dev` 도 같습니다.

```
  이 PC          http://localhost:8787/
  사내 다른 PC   http://192.168.0.42:8787/     ← 실행하면 실제 주소가 표시됩니다
```

아래 주소를 동료에게 알려주면 **같은 사내 네트워크의 다른 PC 에서도 접속**합니다.
받는 쪽은 아무것도 설치할 필요가 없고 브라우저만 있으면 됩니다.

- 이 창이 켜져 있는 동안에만 접속됩니다. PC 를 끄거나 창을 닫으면 끊깁니다.
- 다른 PC 에서 안 열리면 **`사내공유_방화벽허용.cmd` 를 관리자 권한으로 한 번** 실행하세요.
  (사내망·도메인 네트워크에서만 8787 포트를 엽니다. 공용 Wi-Fi 에서는 열지 않습니다.)
- 이 PC 에서만 쓰고 싶으면 `set HOST=127.0.0.1` 후 실행하세요.

> 항상 켜 두려면 사내 서버나 상시 켜 두는 PC 에 이 폴더를 두고 `열기.cmd` 를 실행해 두세요.
> 자세한 방법은 아래 [사내 서버에 상시 띄우기](#사내-서버에-상시-띄우기) 참고.

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 행사 찾기 | 위쪽 검색창에 행사명·주관사·언론사·장소를 입력 (`/` 키로 검색창 이동) |
| 증빙 있는 행사만 보기 | `언론기사 있는 행사만` 버튼 |
| 행사 자료 한 번에 받기 | 목록 오른쪽 내려받기 버튼, 또는 미리보기의 `전체 내려받기` |
| 기사 원문 보관본 받기 | 미리보기 → 관련 자료 → `PDF 저장` |
| 사진 크게 보기 | 미리보기 사진 클릭 (`←` `→` 로 넘기고 `Esc` 로 닫기) |
| 사진 한 장만 받기 | 크게 보기 화면의 `이 사진 저장` |
| 특정 행사 링크 공유 | 주소창의 `#e04` 형태 주소를 그대로 전달 |

### 전체 내려받기에 들어있는 것

행사별 ZIP 한 개에 아래가 모두 들어갑니다. 그대로 제출 폴더에 넣으면 됩니다.

```
20251209_2025 일터혁신 컨퍼런스 — 일터혁신 우수기업 선정.zip
├─ 사진/            긴 변 1920px (인쇄·제출용으로 충분)
├─ 언론기사/        기사 원문 PDF + 지면 캡처 이미지
├─ 영상/            행사 영상 파일 (있는 경우)
└─ 행사정보.txt     일시·장소·주관·참석자·기사 링크·사진 목록
```

> **촬영 원본이 필요할 때** — ZIP 에는 웹용으로 줄인 사진이 들어갑니다.
> 저장소·배포 용량 한도(GitHub 는 100MB 넘는 파일을 거부) 때문이고, 원본 그대로면 591MB 입니다.
> 촬영 원본은 `source/` 와 공유드라이브의 행사 사진 폴더에 그대로 남아 있습니다.

### 서버 없이 파일로 열 때

`index.html` 을 직접 더블클릭해도 열립니다. 다만 브라우저 정책 때문에
**사진과 PDF 가 저장되지 않고 새 탭에서 열립니다**(ZIP 은 그대로 저장).
혼자 잠깐 확인할 때만 쓰고, 평소에는 `열기.cmd` 로 여세요.

## 인터넷 배포 (Vercel + 사내 통합 로그인)

사내망 밖에서도 쓰려고 Vercel 에 배포하고, **다른 사내 서비스와 같은 계정**으로 로그인하게 했습니다.
회사 Keycloak(`api.dvi-ind.com/dauth`, realm `dvi`)을 그대로 씁니다.

**로그인하지 않으면 사진 한 장도 열리지 않습니다.** 화면만 가리는 게 아니라
`middleware.js` 가 `/photos`, `/downloads`, `/articles`, `/assets/data.js` 를 포함한
모든 경로를 검사하므로 파일 주소를 직접 입력해도 401 로 막힙니다.

| 항목 | 값 |
|---|---|
| 방식 | OpenID Connect · Authorization Code + PKCE(S256) |
| 엔드포인트 | 코드에 박지 않고 `.well-known/openid-configuration` 에서 읽음 |
| 검증 | `iss` · `aud` · `nonce` · `exp` 확인 (선택적으로 이메일 도메인까지) |
| 세션 | HMAC-SHA256 서명 쿠키 12시간 · HttpOnly · Secure · SameSite=Lax |

### 1. Keycloak 클라이언트 등록 (백엔드 담당)

realm `dvi` 에 이 사이트용 클라이언트를 하나 만듭니다.

- Client ID: `company-events` (원하는 이름으로 해도 됩니다)
- Standard flow 사용, PKCE `S256`
- **Valid redirect URIs** 에 아래를 정확히 등록 — 이게 빠지면 로그인이 막힙니다

  ```
  https://company-events-theta.vercel.app/api/auth/callback
  ```

- Confidential(비공개) 클라이언트면 Client Secret 을, Public 이면 비밀번호 없이 PKCE 만 씁니다

### 2. Vercel 환경변수

Vercel 프로젝트 → **Settings → Environment Variables**
(Production / Preview / Development 모두 체크)

| 이름 | 값 | 필수 |
|---|---|---|
| `OIDC_ISSUER` | `https://api.dvi-ind.com/dauth/realms/dvi` | 필수 |
| `OIDC_CLIENT_ID` | 1단계에서 등록한 Client ID | 필수 |
| `OIDC_CLIENT_SECRET` | Confidential 클라이언트일 때만 | 선택 |
| `SESSION_SECRET` | 임의의 긴 문자열 (아래 명령으로 생성) | 필수 |
| `ALLOWED_DOMAIN` | `dvi-ind.com` — 비워 두면 인증된 사내 계정 전부 허용 | 선택 |
| `OIDC_SCOPE` | 기본값 `openid profile email` | 선택 |

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

> 이 값들은 **저장소에 넣지 마세요.** 이 저장소는 공개 상태입니다.
> 값을 바꾼 뒤에는 Vercel 에서 **Redeploy** 를 해야 반영됩니다.

### 3. 배포

환경변수를 넣고 **Redeploy** 하면 끝입니다.
빌드는 하지 않고 저장소에 들어 있는 사진·ZIP 을 그대로 내보냅니다 (`vercel.json`).

### 동작 확인

1. 시크릿 창으로 배포 주소 접속 → 로그인 화면이 떠야 합니다
2. 로그인 없이 사진 주소를 직접 열어 봅니다
   → **401 로그인이 필요합니다** 가 나와야 정상입니다
3. `사내 계정으로 로그인` → Keycloak 화면 → 돌아오면 목록이 뜨고 우측 상단에 계정 표시
4. 다른 사내 서비스에 이미 로그인돼 있으면 Keycloak 화면 없이 바로 들어옵니다

### 자주 막히는 곳

| 증상 | 원인 |
|---|---|
| `Invalid redirect_uri` | 1단계의 Valid redirect URIs 에 콜백 주소가 없음. 끝의 `/api/auth/callback` 까지 정확히 일치해야 함 |
| `설정이 필요합니다` 화면 | 환경변수 누락. 화면에 빠진 변수 이름이 표시됨 |
| 토큰 발급 거절 (502) | Confidential 클라이언트인데 `OIDC_CLIENT_SECRET` 이 없거나 값이 틀림 |
| 로그인 후에도 계속 로그인 화면 | `SESSION_SECRET` 미설정 또는 Redeploy 안 함 |
| 로그인은 되는데 403 | `ALLOWED_DOMAIN` 과 계정 이메일 도메인이 다름. 사내 계정 전부 허용하려면 이 변수를 지우세요 |
| 화면은 뜨는데 사진이 깨짐 | `npm run build` 후 `photos/` 등을 커밋·푸시하지 않음 |

> 로그아웃은 **이 사이트의 세션만** 지웁니다. 같은 계정으로 열어 둔 다른 사내 서비스는
> 그대로 유지됩니다. SSO 전체를 끊고 싶으면 Keycloak 의 `end_session_endpoint` 로 보내면 됩니다.

## 사내 서버에 상시 띄우기

담당자 PC 를 켜 둘 필요 없이 항상 접속되게 하려면, 상시 켜져 있는 사내 PC 나 서버에 올립니다.

1. 그 PC 에 [Node.js](https://nodejs.org) 설치 (LTS 버전)
2. 이 폴더를 통째로 복사 (`source/` 는 없어도 됩니다 — 화면 표시용 사진과 ZIP 은 이미 만들어져 있습니다)
3. `사내공유_방화벽허용.cmd` 를 관리자 권한으로 한 번 실행
4. `열기.cmd` 실행

PC 가 재부팅돼도 자동으로 뜨게 하려면, `열기.cmd` 바로가기를 아래 폴더에 넣어 두세요.

```
Win+R  →  shell:startup  →  여기에 "열기.cmd" 바로가기 붙여넣기
```

주소가 바뀌지 않도록 그 PC 에 **고정 IP** 를 주는 편이 좋습니다. 사내 IT 담당자에게
`이 PC 에 고정 IP 와 8787 포트 허용` 을 요청하시면 됩니다.

## 새 행사 추가하기

### 1. 사진 넣기

`source/` 아래에 `구분/행사명_날짜` 형식으로 폴더를 만들고 사진을 넣습니다.

```
source/
├─ 사내 행사/
│   └─ 산업안전보건 교육_260121/     ← 사진 그대로 복사
└─ 사외 행사/
    └─ 포스코 기술나눔 행사_260318/
```

### 2. 행사 정보 적기

`data/events.json` 의 `events` 배열에 항목을 추가합니다. 기존 항목을 복사해 고치는 것이 가장 쉽습니다.

```jsonc
{
  "id": "e13",                                  // 겹치지 않는 번호. 한 번 정하면 바꾸지 마세요
  "folder": "사외 행사/새 행사_260901",           // 위에서 만든 source 폴더 경로
  "category": "사외",                            // 사내 | 사외
  "type": "수상",                                // 목록의 행사구분
  "date": "2026-09-01",
  "title": "행사 이름",
  "subtitle": "한 줄 부제",
  "place": "장소",
  "host": "주관 기관",
  "attendees": "참석자",
  "summary": "행사 개요 한두 문장",
  "notes": ["단체사진 좌측 세번째 ○○○ 상무"],     // 사진 속 인물 위치 등 메모
  "articles": [
    { "press": "언론사", "title": "기사 제목", "url": "https://...", "hasPhoto": true }
  ],
  "videos": [
    { "press": "채널명", "url": "https://...", "marks": ["12:30~ 대표이사 인터뷰"] }
  ]
}
```

### 3. 다시 빌드

```bash
npm run setup      # 처음 한 번만 (빌드 도구 설치)
npm run articles   # 기사 원문을 PDF 로 저장 (이미 받은 기사는 건너뜀)
npm run build      # 사진 변환 · ZIP 묶기 · 목록 갱신
```

모두 프로젝트 폴더에서 실행합니다.

`npm run build` 를 마치면 `index.html` 을 새로 고침하는 것만으로 반영됩니다.

## 폴더 구조

| 폴더 | 내용 | 직접 수정 |
|---|---|---|
| `index.html`, `assets/app.css`, `assets/app.js` | 화면 | 예 |
| `열기.cmd` | 사이트를 띄우는 실행 파일 | 예 |
| `사내공유_방화벽허용.cmd` | 사내 다른 PC 접속 허용 (최초 1회, 관리자 권한) | 예 |
| `package.json` | `npm run dev / build / articles` 명령 | 예 |
| `data/events.json` | **행사 정보 원본. 여기만 고치면 됩니다** | 예 |
| `source/` | 사진 원본 (입력) | 예 |
| `photos/`, `thumbs/` | 화면용으로 줄인 사진 (긴 변 1920px) | 아니오 — 빌드가 생성 |
| `articles/` | 기사 PDF·캡처 | 아니오 — 빌드가 생성 |
| `videos/` | 행사 영상 파일 | 아니오 — 빌드가 생성 |
| `downloads/` | 행사별 전체 ZIP | 아니오 — 빌드가 생성 |
| `assets/data.js` | 화면이 읽는 목록 데이터 | 아니오 — 빌드가 생성 |
| `tools/` | 빌드 스크립트 | 예 |
| `middleware.js`, `api/auth/`, `lib/`, `login.html` | 배포본 사내 통합 로그인(Keycloak) | 예 |
| `vercel.json` | Vercel 배포 설정 | 예 |

`source/` (촬영 원본 547MB) 만 `.gitignore` 로 빼고, 나머지 생성 폴더는 **일부러 저장소에 올립니다**.
Vercel 빌드 서버에는 원본이 없어 사진을 다시 만들 수 없기 때문에, 만들어 둔 결과물을 그대로 배포합니다.
그래서 `npm run build` 를 돌린 뒤에는 `photos/` 등의 변경도 함께 커밋·푸시해야 합니다.
